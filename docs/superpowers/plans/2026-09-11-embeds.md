# Kế hoạch: nhúng nội dung (embed) trong ghi chú

Ngày: 2026-09-11 · Repo: `vibe-chat-fe`, `notion-service` · Bổ sung cho plan blocknote-to-tiptap.

## Quyết định (người dùng đã duyệt)

- Thứ tự: **A (iframe) → C (tệp: video/audio/file) → B (thẻ xem trước link) → D (GitHub/GitLab card)**
- Provider tầng A: YouTube, Vimeo, Loom, Google Maps, Figma, CodePen, GitHub Gist, Spotify, SoundCloud.
- Mạng xã hội (X/Facebook/Instagram): KHÔNG nhúng chính thức (cần nạp script bên thứ ba) →
  dùng thẻ xem trước link ở tầng B.

## Hiện trạng đo được

- CSP ở `next.config` đang **Report-Only**, `frame-src 'self' https:` → cho iframe từ bất kỳ HTTPS.
- Chưa có endpoint upload tệp (chặn tầng C) và chưa có endpoint đọc OpenGraph (chặn tầng B).
- Schema Tiptap là nguồn sự thật, nằm ở CẢ `editor-next/extensions.ts` (FE) và
  `notion-service/.../tiptap-schema.ts` (server). Node mới PHẢI thêm hai nơi cùng lúc.
  Bài học `blockGroup` sáng nay: schema lệch một bên là tài liệu không đọc được.

## Thiết kế tầng A

**Một node `embed`**, không phải một node mỗi provider:
```
embed { provider: string, src: string (URL nhúng đã chuẩn hoá), title?: string, aspect?: '16:9'|'4:3'|'1:1'|'auto' }
```
- **Registry provider** (`src/lib/editor/embed-providers.ts`, thuần TS, có test): mỗi provider gồm
  `id`, `match(url) → boolean`, `toEmbedSrc(url) → string | null`, `aspect`, `label`, `icon`.
  Chỉ registry mới biết biến URL chia sẻ → URL nhúng (vd `youtu.be/ID` → `youtube.com/embed/ID`).
  Server dùng CÙNG registry (đặt ở package dùng chung hoặc copy có test khớp — nêu rõ chọn cách nào).
- **Whitelist là bắt buộc**: `src` chỉ được lưu nếu `toEmbedSrc` trả về từ một provider trong registry.
  Không có "embed URL tuỳ ý".
- **Render**: FE node view = `<iframe src sandbox="allow-scripts allow-same-origin allow-popups"
  allow="..." loading="lazy" referrerpolicy="strict-origin-when-cross-origin">` trong khung giữ
  tỉ lệ; có nhãn provider + nút mở link gốc + xoá. Server `generateHTML` (trang công khai) render
  cùng markup. Markdown cho AI: rơi về `[label](src gốc)`.
- **CSP**: `frame-src` đổi từ `https:` sang danh sách domain của các provider đã chọn. Vẫn giữ
  Report-Only như hiện tại (enforce là việc khác, có checklist riêng trong next.config).
- **Cách dùng**: (1) `/embed`, `/youtube`, `/map`, `/figma`… rồi dán URL; (2) dán URL trần vào
  đoạn trống → nếu khớp provider, hiện gợi ý "Nhúng / Giữ link" ngay tại chỗ.

## Việc tầng A

A1 — Lõi, không UI: registry + test cho 9 provider (mỗi provider ≥ 2 dạng URL thật) · node `embed`
     ở FE `extensions.ts` VÀ server `tiptap-schema.ts` · server: `jsonToHtml` render iframe,
     `jsonToMarkdown` rơi về link · test round-trip json ↔ Y.Doc ↔ html.
A2 — UI: node view React (khung tỉ lệ, nhãn, mở gốc, xoá) · lệnh slash `/embed` + từng provider ·
     bắt dán URL → gợi ý nhúng · CSP whitelist · test.
